# SA2023 – Tentaträning

En statisk studiesajt för kursen **Samhällsanalys & Kommunikation (SA2023)**.

## Funktioner
- Flashcards som vänds genom klick eller mellanslag
- Höger/vänster navigering med knappar eller piltangenter
- Filter efter kursområde
- Tentastilsfrågor inspirerade av tidigare salstentor
- Skrivläge för kortsvar
- Självskattning: Repetera / Nästan / Kan
- Framsteg och egna svar sparas lokalt i webbläsaren
- Automatisk ljus/mörk färgsättning efter systeminställning
- Inga externa bibliotek eller byggsteg

## Publicera på GitHub Pages
1. Skapa ett nytt GitHub-repository.
2. Ladda upp `index.html` (och gärna denna README).
3. Öppna **Settings → Pages**.
4. Under **Build and deployment**, välj **Deploy from a branch**.
5. Välj `main` och mappen `/ (root)`.
6. Spara. GitHub visar därefter länken till sajten.

All funktionalitet ligger i `index.html`, så sidan är lätt att flytta eller ändra.
